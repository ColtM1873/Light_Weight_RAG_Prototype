# 05 · 复盘

## 1. 最难的问题

- 怎么组织Agent编排才能满足题目**严苛的准确性要求**。
- 从零构建RAG过程中，需要解决的若干**文档切分**，**hash验证变动**，**index持久化**，**多粒度检索**实际落地的工程问题。

## 2. 学习收获

- 复习了一下json格式化输出的编写方式，实际体验了**单条消息格式化输出（非传统消息链）**的速度，轻量，低成本和便捷。
- 进一步巩固了**RAG**相关理论知识和工程经验。

## 3. 下一步

- 可以考虑把相关RAG原型应用到自研**Deep Research**（大量的论文的RAG，专业知识库RAG，等）中去。
- 可以考虑在更多合适的地方直接部署 **单条消息格式化输出** 而非传统消息链
