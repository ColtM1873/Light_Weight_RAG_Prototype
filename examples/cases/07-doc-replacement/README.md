# 07 · 替换文档内容对照实验

## 目的

验证「替换文档内容后，同一问题的答案/动作是否随之改变」——即回答确实来自检索到的文档，而不是模型记忆或模板。

## 做法

只改 `D001_员工差旅报销管理制度.md` 两处：

```diff
-版本日期：2024-06-30
+版本日期：2025-01-01

-第五条 ... 其他城市每晚不超过 350 元。...
+第五条 ... 其他城市每晚不超过 600 元。...
```

其余文档、问题、模型、代码、参数全部不变：

```powershell
python run.py ask -q "其他城市出差住宿每晚最多报销多少？" ...
```

两次运行之间执行 `python run.py build-index --force` 重建索引。实验结束后把 D001 原样恢复并再次重建索引。

## 文件

| 文件 | 说明 |
|---|---|
| `original_D001.md` | 原始文档（恢复用） |
| `modified_D001.md` | 替换后的文档 |
| `diff.txt` | 两版差异 |
| `baseline.json` / `baseline.md` | 原始数据下的执行记录 |
| `modified.json` / `modified.md` | 替换数据下的执行记录 |

## 结果对照

| 项 | 基线（original） | 替换后（modified） |
|---|---|---|
| D001 版本日期 | 2024-06-30 | 2025-01-01 |
| 其他城市住宿上限 | **350 元/晚** | **600 元/晚** |
| 合住 1.5 倍推算 | 525 元/晚 | 900 元/晚 |
| 最终答复 | 「最多报销 350 元」 | 「最多报销 600 元」 |
| 引用原文 | 「其他城市每晚不超过 350 元」 | 「其他城市每晚不超过 600 元」 |
| 工具调用 / 步数 | 1 次 / 8 步 | 1 次 / 8 步 |
| Guard 1 / Guard 2 | 通过 / support | 通过 / support |
| 最终整理 finalize | 有 | 有 |

结论：
- **答案和引用随文档内容改变**，说明检索与引用链路是真实的；
- 本次动作结构相同（1 次检索 + finalize），因为问题本身不需要额外工具；答案层面的变化已经足以证明「替换文档 → 答案改变」；
- 两次 Guard 都通过，说明替换后的 600 元同样能被引用校验在 modified 库中找到。

## 恢复验证

- 恢复前 D001 SHA256：`0B7D02691D2A234AEAE72CE99F1E06310A9A37E4C54469F8D7ABDB314E3AB27B`
- 恢复后重新计算 SHA256 与上述一致；
- 重新执行 `python run.py build-index --force`，`solid_sentences.json` 中「其他城市每晚不超过 350 元」出现 1 次、「600 元」出现 0 次；
- 仓库最终提交的是原始文档，替换仅存在于本目录的实验材料中。
